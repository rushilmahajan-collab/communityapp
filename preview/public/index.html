🔧 Troubleshooting Steps:

1. Check Root Directory Setting:

Settings → Root Directory → Should be: preview

2. Check Build Logs:

Deployments → (Latest) → View Build Logs

Look for errors related to Next.js or npm

3. Try Local Build:

cd preview && npm install && npm run dev

4. If still broken:

Delete project and redeploy from scratch
